01 / CONTEXT

A small connected object for a working desk

Shi+ne checks a Notion task list. When a task is completed, a mechanical sunflower rises while the screen face celebrates, then the object settles back into a quiet idle state.

The product is designed to acknowledge work already done—not to send reminders, coach the user, or compete with the task at hand.

DESIGN INTENTCelebrate progress, without demanding attention.
☺

02 / OPPORTUNITY

Make the moment of completion visible

Focused work has small wins. A desk companion can give those moments a gentle physical signal.

The design space narrowed around a presence that only becomes noticeable when something meaningful happens. It should not need attention to function.

03 / RESEARCH

A companion that appears only when it matters

The project explored the space between needy desk pets and passive productivity tools. Task completion brought a short-lived sense of satisfaction, but the surrounding workspace did little to mark the transition from effort to progress.

OBSERVE

Notice the natural rhythm of focused work.

ACKNOWLEDGE

Respond to meaningful progress, not every action.

04 / DESIGN PRINCIPLES

Four principles shaped the experience

01

Witness, not assistant

Do not remind, suggest, or coach.

02

Quiet by default

No sound or notifications. Feedback stays local to the desk.

03

Charm without infantilization

Give the object expression while keeping it at home on an adult’s desk.

04

Honest hardware

Let the display and mechanical flower be visible parts of the design.

05 / FINAL CONCEPT

A flower that rises with progress

The signature gesture is a sunflower lifted by a servo when the task count changes. The screen face blinks, celebrates, and responds to occasional touch interactions.

07 / INDUSTRIAL DESIGN

A soft cube with a grounded base

The body gives the screen a clear orientation while the deep green lower section reads like a planter. The printed enclosure was iterated to make the LCD bezel and flower mechanism manufacturable.

◈

Desk Robo Body

Enclosure proportions establish a stable base for the display and flower mechanism.

The first prints exposed a sharp internal corner around the display bezel. Rounding the edge and splitting the enclosure into bolted parts helped the geometry print more reliably.

08 / TECHNICAL ARCHITECTURE

One small board, several coordinated jobs

The ESP32 V2 connects the display, touch input, servo and Wi-Fi task polling. The device uses a 3.5-inch ILI9486 SPI touch LCD, an SG90 micro servo and USB-C power.

09 / BUILD LOG

Small technical hurdles, solved one at a time

LCD would not wake

Display initialization and board configuration need to match the selected hardware.

The driver targeted the wrong board

Verify the driver and board profile before debugging application behavior.

The 5V backlight problem

The display logic and backlight use different voltage rails; the backlight needs the appropriate supply.

Permanent soldering

Moving from a test setup to soldered connections makes every wire placement harder to reverse.

Notion API onboarding

The integration and task database must be configured and shared correctly before the device can read updates.

The animation library failed to compile

Library and board compatibility need to be resolved before expression work can be tested on-device.

Black flash between frames

Rendering to an off-screen buffer can help reduce visible flashes during face animation.

Failed 3D prints

Print orientation, enclosure splits, and rounded internal corners help make the casing more reliable.

The flower felt mechanical

Movement timing needs to feel like a small celebration rather than a plain servo motion.

The sound question

The product stays quiet so that feedback does not compete with focused work.

10 / REFLECTION

What the project makes clear

Hardware makes decisions tangible. Physical fit and connection issues make iteration slower and more deliberate.

Documentation is part of the artifact. Wiring maps and setup guidance matter to the next builder.

Restraint can be a feature. Quiet feedback can acknowledge progress without demanding attention.

Scope creates room to continue. A prototype is one point in a larger space of possible interactions and forms.
