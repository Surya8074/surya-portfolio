# ComSki Homepage Showcase Asset Manifest

These are existing repository assets reused for the three independent homepage media slots. No images were generated or downloaded as part of this correction.

| Slot | Path | Type | Intended role |
|---|---|---|---|
| Upper | `/surya-portfolio/comski/2nd%20card.png` | PNG | Speaking-practice visual |
| Lower | `/surya-portfolio/comski/3rd%20card%20c.png` | PNG | Writing-practice visual |
| Hero | `/surya-portfolio/comski/4th%20card.png` | PNG | Wide ComSki dashboard / laptop visual |

The three paths are independently configured in `src/comski-home-card-data.ts`. Replace one path and its alt text to update a single slot. Image/video type, object fit, object position, optional poster, and video playback settings are supported by the existing media configuration.

Note: these files were selected from existing assets by their current repository names. Confirm the deployed visual appearance after the site rebuilds; no local browser screenshot comparison or production build was available during this edit.
